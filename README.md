# FUNDING.yml

Add a [sponsorship button in repositories](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository) to advertise that coffee orders can be received with [Maintainers Coffee](https://maintainers.coffee).

**Requirements**:

- Sponsorships toggled "on" from general feature settings for individual GitHub repositories
- Account connected and shipping details added to a Maintainers Coffee profile
- Committed a [`FUNDING.yml`](https://github.com/maintainersdotcoffee/FUNDING.yml/blob/main/.github/FUNDING.yml) file as metadata with contents including the connected username:

```yaml
custom:
  - https://maintainers.coffee/github/username
```
